About

Small tools with a practical purpose.

UncleRiot projects focus on clear Windows utilities that solve specific everyday problems without unnecessary complexity.

Design principles

The projects are built around understandable interfaces, focused feature sets and workflows that remain useful outside a developer environment.

Practical first

Features should reduce friction in real tasks rather than exist only for technical completeness.

Documentation in one place

Detailed technical information remains in each GitHub repository and Wiki. This site provides the more accessible product view.

Open development

Source code, releases, issues and documentation remain publicly accessible through GitHub.
