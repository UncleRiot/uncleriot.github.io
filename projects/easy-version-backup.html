Versioned folder backups

EasyVersionBackup

Backups without turning it into a science project.

Pick what should be backed up, choose where it should go and let the tool keep a few versions around. Manual or automatic, folders or ZIP files — whatever fits the job.

View repository ↗Open the wiki ↗

What it does

  • Runs backups manually or on a schedule
  • Handles several source and target pairs
  • Saves as normal folders or ZIP archives
  • Skips files and folders you do not want
  • Cleans up old versions automatically
  • Sits quietly in the system tray

Need the details?

The Wiki explains setup, backup jobs and the bits that are not completely obvious at first glance. It is there so you do not have to guess your way through it.
